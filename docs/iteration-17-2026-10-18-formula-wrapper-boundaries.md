# Iteration 17：重复公式包装与方括号边界

**版本：** userscript `1.15.10`；FastAPI `1.7.21`。
本次修复网页公式来源已有包装时的重复包装，以及公式末尾方括号与内部标记
冲突的问题。单个公式的最终剪贴板仍使用裸 LaTeX；正文或多个公式、内部翻译
与朗读、API 结果和文档写回继续使用规范公式包装。原有矩阵兼容、ChatGPT
源码保留、WPS `\bar` 简写规范化，以及轻量加载器登录启动、完整服务按需
启动方案不变。本轮范围是已知公式相关问题及其共用处理链路，不代表整个软件
不存在其他缺陷。

## 1. 用户反馈

用户从网页复制公式后，粘贴到 **WPS 自带公式编辑框** 并转换成专业模式，
公式外出现多余圆括号。反馈的源码为：

```latex
\(\sigma_0,\sigma_1,\ldots,\sigma_m\in\Sigma[x]\)
```

单独复制该公式，传给公式框的预期内容是：

```latex
\sigma_0,\sigma_1,\ldots,\sigma_m\in\Sigma[x]
```

这里只应移除标记数学区域的 `\(`、`\)`，不能删除 `\Sigma[x]` 中的 `[x]`。
数学圆括号、区间方括号、集合括号、矩阵括号也不是可任意删除的包装。

## 2. 两处边界问题

### 来源已经带有公式包装

网页的公式 metadata 可以提供完整 `\(...\)` 或 `\[...\]`，而不只是公式
本体。旧路径在提取后再加自己的包装；最终复制只剥离一层时，内层包装仍会
进入 WPS 公式框。单测只使用不带包装的 metadata 或只测试一次包装，不能
覆盖这一真实选区链路。

修复先识别完整公式边界并规范化重复包装。网页 DOM 提取现在直接输出一层
规范 `$...$` / `$$...$$`，不再生成旧的 `[[MATH:...]]` 标记。只有整个选区确实是单个公式且没有
正文时，最终复制才输出裸 LaTeX；正文或多个公式继续保留 `$...$` / `$$...$$`，
不能用简单删除所有 `\(`、`\)`、`[`、`]` 的方式修复。

### 公式末尾 `]` 与内部标记相邻

历史内部 `[[MATH:...]]` 一类标记的闭合符也使用方括号。公式自身以 `]` 结尾时，
如 `\Sigma[x]`，边界附近会出现连续右方括号。按首次遇到 `]]` 就结束的匹配
会把公式的右方括号吞入标记，造成公式截断，另一个 `]` 还可能落入正文。

旧标记仍受兼容支持：解析同时保留公式本体和内部标记的边界，而不是在复制
结果末尾猜测补上一个方括号。规范化、单公式识别和朗读分段对这类输入使用
一致的边界规则；真正的数学方括号、正文中的方括号和相邻公式不能相互吞并。

### 前后端共同处理

网页核心与 `addons/shared/reading-core.js` 同步处理公式包装。Python
`document_formula.py` 的 `read_formula_wrapper`、`unwrap_formula_wrappers`、
`iter_formula_wrappers` 作为共用解析入口；`server.py` 的翻译公式保护、还原
及输出规范化接入该边界逻辑，正文转原生公式也使用修复后的解析器。这样旧
标记或重复包装到达后台时，不会只在最终复制时被修正而仍破坏翻译和文档转换。

### 空白、注释与不完整输入

公式内部空白与注释按源码保留，包括文本命令中的连续空格，以及终止 `%`
注释所需的换行；不能因普通正文的空白整理而改变公式文本或让注释吞掉后续
闭合标记。转义的百分号不是注释，文字命令中的公式样式符号也不应被当成
新的包装剥离。

畸形或未闭合的 legacy 标记原样保留，不猜测修补、不将其内部片段误认成另一
个有效公式；规范化后再次解析也不应改变这个判断。单美元行内公式不会跨
普通正文换行寻找另一个美元符号，以免吞掉跨行正文或货币文本；终止公式
注释所必需的换行仍保留，相邻公式也分别保留。

## 3. 对外契约

| 内容与操作 | 输出 |
|---|---|
| 只复制一个完整公式 | 去掉重复数学包装的裸 LaTeX，保留数学括号 |
| 复制带公式的正文 | 保留正文与规范 `$...$` / `$$...$$` |
| 一次复制多个公式 | 保留各公式边界，不合并成一个裸公式 |
| 文档插件公式或译文复制 | 与网页选区及译文卡使用同一最终剪贴板规则 |
| 内部翻译、朗读、API 结果、文档写回 | 使用规范公式包装，不被剪贴板专用兼容处理覆盖 |
| 畸形或未闭合的 legacy 标记 | 原样保留，不猜测修补或拆出内部伪公式 |

上一版矩阵兼容仍保留：括号矩阵使用等价 `\left` / `\right` 与 `matrix`，
合法矩阵行距选项如 `\\[2mm]` 可移除，但换行、行列和数学括号必须保留。
本次规则处理在本地完成，不需要调用大模型或启动远程服务。

## 4. 升级与复查

1. 将 Tampermonkey 中实际安装的脚本更新至 **`1.15.10`**，然后刷新来源网页。
2. 仅选中目标公式，点击本插件浮动工具条的 **Copy**，不要改用网页自身的复制按钮。
3. 在 WPS 自带公式编辑框的 LaTeX 输入模式中粘贴，再转换为专业模式。
4. 核对没有额外外围圆括号，`\Sigma[x]` 的右方括号仍完整；矩阵的行列也应保留。
5. 文档插件加载共享脚本后，需关闭并重新打开任务窗格。
6. 本地后台也需更新至 **`1.7.21`**。若服务正在运行，重启它以加载新代码；
   未运行时可等下次按需启动。本次复制边界修复不要求启动 Ollama 或连接服务器。

仓库文件、GitHub Raw、Tampermonkey 已安装副本和 Greasy Fork 发布页是不同
更新环节。修改仓库或更新本文档不代表浏览器副本已升级，也不代表 Greasy Fork
已经同步。带正文或多个公式的内容应粘贴到正文，再通过文档插件的
**转换为原生公式** 处理，不应放进单个公式框。
